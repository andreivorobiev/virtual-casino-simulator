4. Require pull request reviews.
5. Require status checks: CI, Contract Tests, Module Boundary Tests, Docs, Comment Density.

7. Block direct pushes to `main`.
8. Connect Codex to the repository.
9. Start with `FIRST_PROMPT_FOR_CODEX.md`.
10. Use one GitHub issue and one Codex conversation per module task.
