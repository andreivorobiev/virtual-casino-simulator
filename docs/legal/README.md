# Legal Docs

Requirements: LIC-001, LIC-002, TERMS-001, TERMS-002, TERMS-003, TERMS-004 (registered in `docs/requirements/requirements.json`, which is authoritative for their current status).

This folder separates source-code licensing from private beta use of the running app.

- `../../LICENSE` grants the Apache License, Version 2.0 for the repository source code.
- `../../NOTICE` records project attribution and the boundary between code licensing and app use terms.
- `terms.md` covers private beta use of the local toy simulator.
- `privacy.md` covers privacy expectations for the local toy simulator.

The Virtual Casino Simulator is a toy simulator for local fake-money play. It is not a gambling site, not a casino operator, not a payment product, and not a real-money wagering service. Play tokens have no cash value and cannot be redeemed, sold, transferred, exchanged, or withdrawn.
