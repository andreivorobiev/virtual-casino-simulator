# Issue #149 Distinctness Evidence

Acey-Deucey / In-Between is distinct enough for an isolated draft implementation slice, pending #77 count acceptance.

| Game | Existing or proposed rule profile |
| --- | --- |
| Hi-Lo | One exposed card, player predicts higher or lower, equal rank refunds. |
| Red Dog | Six-deck ante-first spread game with pair/consecutive automatic outcomes, spread odds, and optional matching raise. |
| Acey-Deucey | Two boundary cards are exposed before any play-token wager; player may pass or wager before the third card; strict inside pays even money; outside and boundary ties lose. |

The implementation therefore stays game-local and does not claim shared catalog registration, 20-game count acceptance, permanent requirement allocation, or visual/long-suite integration.
