# Issue #137 Fan-Tan Isolated Slice

Fan-Tan proved distinct and countable for a draft implementation slice because its core mechanic is a covered pile counted down by repeated groups of four, with settlement determined by the final residue `1`, `2`, `3`, or `4`. That is mechanically separate from the repository's card-comparison, wheel, draw, pattern, and slot games.

This artifact parks the module descriptor proposal at `fan_tan.module.proposal.json` until issue #77 performs shared catalog, manifest, requirements, visual-matrix, compatibility, and long-suite integration.
